# Double-Coyc Bats 🦇

Коллекция полезных скриптов (`.bat`) для Windows, упрощающих работу с системой.

## 📦 Список утилит

*   **[eject.bat](eject.bat)** — Безопасное извлечение USB-флешек. Скрипт сам находит и принудительно закрывает программы, которые блокируют накопитель (с сохранением или без — в зависимости от версии).
*   **[check_usb.bat](check_usb.bat)** — Диагностика USB. Показывает информацию о диске, статус PnP, а также перехватывает ошибки извлечения (Veto), если флешка не хочет извлекаться.
*   **[open-cisco.bat](open-cisco.bat)** — Запуск Cisco Packet Tracer (версии до 9.0.0) с автоматической настройкой локального прокси на `127.0.0.1:9999` для обхода ограничений.
*   **[add-cisco-firewall.bat](add-cisco-firewall.bat)** — Добавляет правило в Брандмауэр Windows, блокирующее сетевую активность Cisco Packet Tracer (требуются права администратора).
*   **[Add-Admin-as-Folder-Owner-for-Happ.bat](Add-Admin-as-Folder-Owner-for-Happ.bat)** — Исправляет владельца и права доступа (ACL) папки, в которой живёт служба Windows. Лечит ошибки установщика *«Owner is outside the trusted system principals»*, *«Access control entry grants rights outside the trusted system principals»*, *«Установщику не удалось проверить права доступа к папке»*, а также *«Служба Happ Client недоступна (ошибка 1060)»*. Скрипт универсальный (Happ — лишь типовой случай), меняет права только у указанной папки и не трогает родительский каталог. Есть режимы `--check` (только отчёт) и `--restore` (откат). Требуются права администратора. [Подробнее ↓](#-подробнее-права-доступа-для-служб-happ)


## 🚀 Как использовать

1. Скачайте нужный `.bat` файл (или клонируйте весь репозиторий).
2. Запустите скрипт двойным кликом. 
3. Некоторые скрипты (например, для брандмауэра) могут потребовать прав администратора — в этом случае скрипт сам запросит повышение прав (UAC).

## 🛠 Подробнее: права доступа для служб (Happ)

### Какую проблему решает

При установке Happ (а также любой другой программы, которая регистрирует
службу Windows под `LocalSystem`) установщик может отказаться работать:

```
Owner is outside the trusted system principals.
Access control entry grants rights outside the trusted system principals.
```

В интерфейсе установщика это выглядит как «Установщику не удалось проверить
права доступа к папке», а после установки — «Служба Happ Client недоступна
(ошибка 1060)».

### Почему так происходит

Служба под `LocalSystem` — это процесс с правами `SYSTEM`. Windows (Service
Control Manager) не разрешает регистрировать такую службу, если её `.exe`
лежит в папке, которую может изменить обычный пользователь, или если
владелец папки не входит в доверенные субъекты. Типичные причины:

* папку создал обычный пользователь, поэтому её владелец — SID пользователя,
  а не `Administrators`/`SYSTEM`;
* папка скопирована с другой машины или из другой установки Windows
  (владелец — «чужой» SID, который уже не резолвится);
* папка наследует `Users: Modify` от родительского каталога
  (например, `D:\Programs`, созданного из-под пользователя).

### Что делает скрипт

Скрипт приводит **только указанную папку** к состоянию, которое Windows
принимает:

| Свойство | Значение |
|---|---|
| Владелец | `BUILTIN\Administrators` |
| ACL | `SYSTEM` — полный доступ, `Administrators` — полный доступ, `Users` — чтение и выполнение |

Родительская папка не изменяется. Если целевой папки ещё нет, скрипт
создаст её с правильными правами — установщику останется только положить
туда файлы. Службы, реестр и скачивание чего-либо скрипт не трогает.

### Использование

Перетащите папку на `.bat` или запустите из консоли:

```bat
:: подготовить папку (режим по умолчанию)
Add-Admin-as-Folder-Owner-for-Happ.bat "D:\Programs\Happ"

:: только проверить, ничего не меняя (права администратора не нужны)
Add-Admin-as-Folder-Owner-for-Happ.bat "D:\Programs\Happ" --check

:: откатить строгие права и вернуть наследование
Add-Admin-as-Folder-Owner-for-Happ.bat "D:\Programs\Happ" --restore
```

| Режим | Что делает | Нужен админ |
|---|---|---|
| `prepare` (по умолчанию) | владелец `Administrators`, ACL `SYSTEM:F / Administrators:F / Users:RX` | да |
| `--check` | показывает владельца и наличие записи у недоверенных субъектов | нет |
| `--restore` | снимает строгие права и возвращает наследование от родителя | да |

`prepare` и `--restore` сами запрашивают повышение прав (UAC). Коды возврата:
`0` — папка пригодна для службы, `1` — ошибка, `2` — неверные аргументы.

### Как проверяется результат

Отчёт не зависит от языка Windows: скрипт сравнивает **SID**
(`S-1-5-32-544`, `S-1-5-32-545`, …), а не локализованные названия групп, и
ищет любого недоверенного субъекта (`Users`, `Authenticated Users`,
`Everyone`, `INTERACTIVE`, `SERVICE`, `NETWORK`) с правом записи.
Готовая к установке папка выглядит так:

```
Trusted owner         : yes
Write access, untrusted: none
RESULT: OK - this folder is safe for a LocalSystem service binary.
```

### Чем отличается от первой версии скрипта

Первая версия выставляла `Users: RX` на **всю** папку программ навсегда и
попутно ломала все портативные программы, которые хранят конфиг рядом с
`.exe` (Notepad++, VS Code, AyuGram и т. п.): у них пропадала запись и они
показывали «Отказано в доступе» при сохранении настроек или сессии. Текущая
версия:

* меняет права только у папки службы и никогда не трогает родительский каталог;
* идемпотентна — `icacls /grant:r` заменяет ACE, а не добавляет новые,
  поэтому повторный запуск ничего не дублирует;
* умеет откатываться (`--restore`) и проверяться (`--check`);
* создаёт папку сама, если её ещё нет, — отдельная подготовка родителя не нужна.

### Если после старой версии уже сломались портативные программы

Верните наследование прав родительской папке (нужны права администратора):

```bat
Add-Admin-as-Folder-Owner-for-Happ.bat "D:\Programs" --restore
```

После этого права возьмутся из корня диска, и запись снова появится.
Строгие права для самой папки службы (`...\Happ`) при этом не пострадают:
их можно вернуть командой `prepare` перед следующей установкой или обновлением.

### Требования

Windows 10/11 (работает и на 8.1+), встроенный PowerShell 5.1,
права администратора для `prepare` и `--restore`.

## ⚠️ Важно
Скрипты используют системные вызовы (CIM/WMI, настройки реестра, netsh). Антивирусы (включая Defender) могут реагировать на них как на «подозрительные». Это нормально для системных утилит. Код полностью открыт, вы можете изучить его перед запуском.
